# Space Oddity Tools

A small static website with tools and calculators for the game Space Oddity, hosted on GitHub Pages.

## Run locally

Open `index.html` in a browser. No build step is needed.

## Deploy to GitHub Pages

1. Push this repository to GitHub.
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*. Then pick the `main` branch and the `/ (root)` folder.
4. Save. After a minute or so, the site is live at `https://<your-username>.github.io/<repo-name>/`.
